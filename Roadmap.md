# ProxyX — Roadmap

This roadmap lists the project milestones in order. We complete one milestone at
a time and only move on when the current one fully works (see the Definition of
Done at the bottom).

Legend: [x] done  ·  [~] in progress  ·  [ ] not started

## Versioning

Semantic Versioning (MAJOR.MINOR.PATCH), starting at 0.1.0.
v1.0.0 = first stable release. Stable milestones are tagged (e.g. v0.1.0).

## Definition of Done (applies to every milestone)

- [ ] All milestone objectives complete
- [ ] App builds with no errors

- [ ] Changes committed to Git
- [ ] Documentation updated
- [ ] Learning checkpoint answered
